# 合约趋势训练台

一个面向新手的合约趋势分析教学系统，使用本地网页直接运行。

## 功能

- 训练中心：阶段进度、今日路线、行情覆盖地图和个性化下一步
- 看图工作台：基于 TradingView Lightweight Charts 的时间序列图表，支持 Binance 风格蜡烛、Heikin Ashi 平均 K 线（合成值明确标识）和分时线；独立量能刻度的成交量副图与 VOL MA5/10/20、可切换的 SMA5/10/20/60/120 与 EMA20/60、可选结构点、RSI/MACD/KDJ/布林带及常用参数编辑；图表库不可用时仍按主图、成交量和各指标副图显示完整读数
- 币安式图表操作：BTC/ETH/SOL Binance USDⓈ-M 永续公开行情切换、15 个常用 K 线周期、OHLC 十字光标、拖动缩放、趋势线/水平线/斐波那契、绘图磁吸、全屏与视图重置；历史盲测只开放已有 Binance 现货快照的 1m/5m/1H，其他模拟周期不是历史样本
- 图表轻量指标组合：指标弹层提供“清爽观察 / 趋势对照 / 动能观察”三套预设，默认隐藏多余均线和量均线；可按需添加 SMA、EMA、RSI、MACD、KDJ、BOLL、SAR，预设状态会保存并给出对应学习提示
- 首页学习路径：用“训练路线 + 三步闭环 + TRAINING STACK + LEARNING LOOP”收拢入口，从概念/阶段课程进入看图训练，再从复盘弱项回到对应内容；首页能力卡不创建旁路流程
- 专项训练：趋势延续、震荡、假突破、回踩、反转等常见行情题
- 历史训练：普通回放默认使用 Binance USDⓈ-M BTCUSDT 永续历史快照（1m、5m、1H），可切换现货历史；每个固定快照只纳入 499 根已闭合 K 线。课程固定锚点仍绑定已复核的现货样本，不能把索引套到永续数据。训练设置支持 10–475 根自定义长度（另保留 24 根历史用于预热和起始空间），以及 60/120/300 根快捷长度；支持双盲判断和逐根自由操盘。1D/1W/1M 因没有本地可复核快照而明确禁用。永续快照不含资金费率和持仓量
- 模拟操盘：在历史回放旁直接开多、开空、平仓，支持保证金、杠杆、仓位快捷比例、止损、止盈、手续费和滑点近似
- 行为复盘：证据覆盖、理由完整度、计划盈亏比和下一轮训练建议
- 本地档案：保存训练场次、模拟交易和错题重练记录，可在刷新后继续查看

## 图表操作

- 聚焦 K 线图后，用左右方向键逐根查看，Home/End 到已加载范围首尾；Esc 或 Tab 离开恢复最新读数，不推进历史回放。图例可单独聚焦并用方向键横向滚动。
- 主图与各副图分别显示指标读数，长图例可横向滚动；移动十字线时保留滚动位置。图表库不可用时，基础图表按屏幕宽度重新排版，指标图例保持可读字号。
- 专业图底部 `%`、`log` 切换主图价格坐标，自动按钮控制价格自动缩放；拖动价格轴后关闭自动缩放，双击价格轴恢复。量能与振荡指标保持各自刻度。
- 绘图工具栏的磁铁按钮可切换磁吸；开启后，新建或拖动锚点靠近当前显示 K 线 OHLC 12px 内时吸附到最近价格，分时图吸附收盘价、HA 吸附合成 OHLC。状态在当前浏览器保存，默认关闭。
- EMA、SMA、量均线、结构点及指标参数保存于当前浏览器；刷新后恢复。开始指定课程时，课程可切换相应指标。窗口缩放与全屏保留专业图当前可见时间范围。

测试截图和临时验证产物不放入项目仓库，避免影响下载和教学使用。

## 启动

双击 `一键启动趋势训练台.bat`，或在当前目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4173/>。

实时行情使用 Binance USDⓈ-M Futures K 线公开只读接口；普通历史回放可选择匹配的 USDⓈ-M 永续快照，也可选择现货。课程固定锚点保留 Binance Spot 来源，且设置中锁定现货，避免错用索引。页面、训练档案、报告和 CSV 会标明来源；历史快照是固定数据，不会自动滚动更新；具体采集时间与校验和见 `historical-snapshot-manifest.json`。永续快照不含资金费率或持仓量。旧记录没有来源字段时按未知来源导出。模拟教学与模拟交易均不连接交易账户、不执行真实订单，也不构成投资建议。
